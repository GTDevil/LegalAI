Before a real call / असली कॉल से पहले

Checking live setup…

The demo voice on this PC is only for practice. A live call uses a neural Indian woman (Swara) or man (Madhur) voice through Vapi, so it sounds like a person on the phone.

  1. Permission to call that person (TRAI / DND — ask your lawyer).
  2. Prepaid credit, and a number that can dial +91.
  3. A Vapi account: put VAPI_API_KEY and VAPI_PHONE_NUMBER_ID in a .env file (copy .env.example).
  4. Open this desk at http://127.0.0.1:8000 (Start-LegalAI.bat or run_web.py), not only as a saved HTML file.
  5. First live test: one phone that you own. Then tick Live real call.

Full checklist: see docs/LIVE_CALLING.md in the project folder.
